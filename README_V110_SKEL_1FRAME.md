# V110 · SKEL single-frame gate

V110 es una puerta de validación, no una animación final. El objetivo es impedir repetir el problema de V108: no se pasa a una secuencia hasta que un único frame esté bien registrado.

Entrada: 15 landmarks XYZ del puente V109.1.
Modelo: SKEL oficial aportado por el usuario (`skel_male.pkl` o `skel_female.pkl`).
Salida esperada: articulaciones SKEL superpuestas al objetivo y error articular cuantificado.

SKEL no se incluye ni se descarga automáticamente. El código/modelos SKEL tienen condiciones de licencia propias. Para uso clínico/comercial debe resolverse la licencia correspondiente con sus titulares.
