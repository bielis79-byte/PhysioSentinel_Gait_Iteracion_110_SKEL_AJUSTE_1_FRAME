# V107.4 · Validación articular cuantitativa

Esta iteración es una prueba de aceptación de la cadena V104 → GLB pre-riggeado. No modifica la cinemática. La validación usa los orígenes mundiales reales de los nodos anatómicos del GLB y los compara con los landmarks V104 del mismo frame. En modo Rig + Esqueleto, cian = V104, magenta = GLB y rojo = error.
